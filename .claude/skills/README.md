# Skills Sandbox

Personal sandbox for AI experimentation, exploration, and skill development. This is a low-stakes area for trying new approaches, prototyping ideas, and learning.

## Guidelines
- **Experimental** — This is for exploration and iteration
- **Protected** — Keep work-in-progress files here before promoting to main directories
- **Learning** — Use for skill-building and AI collaboration experiments
- **Disposable** — Files here can be deleted or refactored without impact

## Structure
```
.claude/skills/
  [skill-name]/
    README.md         — Skill overview
    exploration.md    — Notes and experiments
    [work files]
```

## Example Skills
- prompt-engineering/
- data-analysis-templates/
- decision-framework-prototypes/
- [Add more as you develop]

## Promotion Path
When a skill matures:
1. Move from `.claude/skills/[name]/` to `capabilities/[name]/`
2. Formalize with spec.md and structured documentation
3. Create decision/brief documents as appropriate
4. Update README to link to mature capability
