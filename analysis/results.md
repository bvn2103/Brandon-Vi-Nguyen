# Integer-search analysis results

This file is generated by running `python3 analysis/integer_search.py` from the repository root. It reports the best allocation found by enumerating integer (T,M,C) allocations subject to bed caps and labor pools.

To reproduce:

1. Ensure you have Python 3.8+.
2. From the repository root run:

   python3 analysis/integer_search.py

3. The script will write `analysis/results.md` with the top allocation and a Top-10 list by profit.

Notes

- The script includes the hand-check asserts from capabilities/marginal-analysis/spec.md. These must pass before results are produced.
