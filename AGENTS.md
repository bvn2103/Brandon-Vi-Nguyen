# AGENTS

## AI Collaboration Conventions

This file documents the canonical protocols and conventions for AI-assisted work in this repository.

### Core Principles
- **Explicitness** — State assumptions and reasoning clearly
- **Traceability** — Link decisions back to source data and analysis
- **Iterability** — Structure work for refinement and feedback
- **Separation of Concerns** — Keep briefs, analysis, and decisions distinct

### Session Workflow
1. **Before** — Write a brief (scope, hypothesis, success criteria)
2. **During** — Use AI for ideation, code, analysis, writing
3. **After** — Document decision/recommendation with rationale
4. **Log** — Record significant sessions in `prompt-log.md`

### File Organization
- `docs/briefs/` — Pre-work planning (hypothesis, scope, deliverables)
- `docs/decisions/` — Post-work documentation (findings, recommendations)
- `data/` — Source materials with attribution
- `analysis/figures/` — Charts, models, and outputs
- `capabilities/` — Full capability documentation (spec + implementation)

### Documentation Standards
- Markdown format throughout
- Include source/provenance for data
- Use version numbers for iterative work
- Cross-reference related documents
